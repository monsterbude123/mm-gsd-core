# 遥测

两路遥测,都是**纯记录**:机械写下已经发生的事,不需要任何人记得写,写失败也绝不阻断流程。

## 门禁运行遥测

检查器每跑一次自动追加一行到用户主目录的 `mm-gsd-runs.jsonl`(时间 / 项目 / 模式 / 推导状态 / 报错 / 警告 / 退出码)。

- 聚合呈现:`mm-gsd check --stats` 报三样最有用的东西 —— **门禁失败率**、**同一项目反复失败次数**(反复失败多半是死锁嫌疑:门禁要的东西做不到,不是内容质量差)、**高频报错类型排行**;`--all` 看全部项目。
- 这套机制的第一版是「agent 每步手工追加一行」,跑完一个真实项目一个文件都没有 —— **需要自觉的探子等于没有探子**,所以记录长在每步必跑的检查器上。

## 工具遥测

安装时加 `--hooks` 装上工具遥测(见[安装与更新](install-update.md))后,宿主每次工具调用机械记一行到用户主目录的 `mm-gsd-tools.jsonl`(时间 / 目录 / 工具名 / 命令头)。

- **隐私口径**:只记工具名与命令头(截断到 140 字符),**不记文件内容全文**;子代理派发行另记角色名与提示词开头(独立字段)。
- 日志超 8MB 自动轮转(只留一代);与门禁运行遥测分文件 —— 两者量级差一个数量级。
- 呈现:`mm-gsd check --stats --tools` 聚合工具调用次数、子代理派发与角色分布、近似时长(窗口 = 派发到该项目下一次派发,末次标「进行中」);过程看板的遥测视图读同一份本机日志,按天迷你图 + 工具分布(见[过程看板](board.md))。

## 关闭

- 关门禁运行遥测:环境变量 `GSD_TELEMETRY=0`。
- 关工具遥测:环境变量 `GSD_TOOL_TELEMETRY=0`(全停,零写入)。
- 遥测只落本机用户主目录,**不存在任何外发通道**;看板亦不对任何外部发请求。
