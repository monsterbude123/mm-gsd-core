# 安装与更新

## 安装

一条命令(npm / npx):

```bash
npx mm-gsd-core                 # 安装到用户技能目录 ~/.agents/skills/
npx mm-gsd-core install --local # 安装到当前项目的 ./.agents/skills/
npx mm-gsd-core install --hooks # 顺带安装宿主 hook(危险操作拦截 + 工具遥测,见[守卫](guards.md)与[遥测](telemetry.md))
```

- 零依赖,要求 Node 18 以上,跨 Windows / macOS / Linux。
- 装完是 7 个技能:讨论、计划、执行、验收、显式校验计划、诊断、流程总控。
- 默认目的地是**用户级** `~/.agents/skills/`(本机所有项目共享);`--local` 只装进当前项目。

也可以手动安装:克隆仓库后把各技能目录拷进技能目录。手动拷贝没有版本清单,体检会如实报「版本不可追溯」。

### 首装与更新的分工

- **install(首装)尊重已有内容**:同名技能已存在且内容相同就跳过;内容不同,先把原内容备份到用户主目录的 backups 目录(按技能名加时间戳命名),再覆盖。
- **update(更新)是机械覆盖**:不比对、不提问,已装技能与宿主卡直接盖成包里这份。真有自定义需求的用户应该改技能定义本身,而不是指望更新保留本地改动。

```bash
npx mm-gsd-core update          # 覆盖更新用户级安装(宿主卡一并刷新)
npx mm-gsd-core update --local  # 只更新当前项目的安装(跳过宿主卡)
```

## 版本与体检

- `mm-gsd --version` 打印版本号。
- 每次安装 / 更新都会在安装目录写一份**版本清单**:版本、来源、时间、每个技能的指纹。
- `npx mm-gsd-core doctor` 只读体检:宿主环境、每个技能的已装状态、已装版本与当前包的差异 —— 有漂移会提示「跑一次 update 机械覆盖」,动词统一,不让你猜。

## 卸载

```bash
npx mm-gsd-core install --uninstall   # 移除已装技能,并清掉安装目录里的版本清单
```

## 边界

- 仓库是真理源,安装目录是派生产物:改了逻辑先改仓库,再同步到安装(发布走 npm;开发期可从仓库直接装,走与 npm 完全相同的安装路径)。
- 备份永远不落在技能目录里 —— 留在里面会被宿主注册成第二个技能。
- hooks 机制没验证过的宿主只装技能、不装 hook:宁可不装也不写坏宿主配置。
