# 过程看板

`mm-gsd web` 起一个本机网页看板,实时渲染项目的流程状态。零依赖,只绑定本机回环地址(127.0.0.1),默认端口 4620,`--port` 可换。

```bash
mm-gsd web               # 起看板,并把当前目录注册进看板名单
mm-gsd web --port 5000   # 换端口
mm-gsd web --add <目录>   # 把另一个项目目录追加进名单
```

## 多项目

- 看板支持同时看多个项目:全局名单存在用户主目录(`~/.agents/mm-gsd-board.json`)。
- 启动时**自动注册**当前目录;`--add <目录>` 手动追加别的项目。
- 端口已被占用时不崩:把当前目录注册进名单后,打印**运行中的看板地址**然后退出 —— 刷新已开的看板就能看到新项目。
- 左侧项目列表常驻:点名字切换项目;目录已删除的项目灰显(名单不自动摘除)。
- 名单每请求现读:另一个终端新注册的项目,刷新当前看板就能看见。

## 五个视图

左侧导航切换(地址栏 hash 路由,刷新不丢视图):

1. **总览**(默认):phase 总览表,一行一个 phase(五步进度 / 票数 / 需求认领 / 交付状态 / 挂账数);表上方是依赖拓扑图(见「依赖拓扑」);顶部筛选条(phase 状态 / 只看有挂账 / 需求认领状态);点行进详情面板(工件清单、认领的需求、相关批注、用户原话折叠块)。已随交付声明产品面、但台账还没有对应交付行的需求,会在总览顶部出黄条提醒。
2. **需求溯源链**:每条需求一行 —— 原话一句话 → 认领票;新增需求无人认领标红;基线需求单独标灰;支持按关键词过滤。
3. **欠账**:三源合并 —— 未闭环的本地账问题、待消化批注、未清偿挂账;挂条件 / 已关闭的项进折叠区展示但**不计数**(有处置理由的不算欠账,未分类的诚实计入)。
4. **遥测**:工具调用按天迷你图 + 工具分布排行;数据来自本机日志,只读、不外发;没有记录时给文案,不画空图。
5. **批注**(见下节)。

## 依赖拓扑

总览页在阶段总览表**上方**画一张依赖拓扑图(图在上、表在下):每个阶段一枚编号圆片,已交付与进行中异色;依赖箭头自上而下,上层是先做的阶段;图上方有一行文字摘要(阶段数 / 依赖条数 / 最长链层数)——一句话能说清的不画图,图不替代结论。

- 依赖关系来自阶段清单里**阶段行尾的依赖注记**;没写注记的阶段视为无依赖,自己占最上层。
- **点任意圆片**打开该阶段的详情面板,与点总览表行是同一个下钻。
- 环状依赖会被**剪断**而不是画到挂死;指向不存在阶段的依赖**直接丢弃**,不画悬空箭头;深浅两套主题下都保持可读。

## 批注

批注是看板**唯一的写通道** —— 看板对项目数据目录(.planning)只读,唯一能写的是批注:

- 在批注视图选目标、选类型、写内容提交;在总览行、需求行、问题条目上点「批注」按钮会预填目标并聚焦。
- 目标写法:需求目标以 `REQ-` 开头的编号;阶段目标写 `phase:` 加阶段号;本地账问题用其编号。
- 类型四种:**需求遗漏**(补需求走确认门)/ **方向不对**(回讨论重开决策)/ **验收不过**(触发点修分流)/ **备注**(记录参考)。
- 提交后落进该项目数据目录的批注文件,状态为 open;在 agent 会话里说「有新批注」即可触发消化,消化后标已消化;验收不过的未消化批注会让检查器提醒走点修分流。
- 批注可选项目:提交随当前查看的项目走,落该项目自己的批注文件,不串写。

## 其他行为

- **双主题**:默认跟随系统深浅色,头部按钮手动切换,选择记忆在浏览器里。
- **自动刷新**:每 15 秒拉一次状态,可暂停;服务失联时状态条给提示,不白屏。
- **零外部请求**:无第三方脚本、字体、图表库 —— 图表是内联矢量图。

## 边界

- 看板只做展示与批注,不提供改工件的能力;状态推导的单一来源是检查器,看板不含推导。
- 某项目还没初始化流程工件时,对应视图给空态文案,不报错。
