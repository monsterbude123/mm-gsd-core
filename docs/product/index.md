# mm-gsd-core 产品文档

mm-gsd-core 是从 GSD 蒸馏出的极简开发流程核心:**把"散文约定"换成"机器门禁"**。
项目按 phase 推进,每个 phase 走五步循环(讨论 → 计划 → 执行 → 验收 → 交付),每一步都有能跑的检查器盯着 —— 每步收尾的动作是「跑检查器转绿」,不是「更新状态文件」。

按能力域分篇,每篇只写可观察的行为、用法与边界:

| 篇 | 内容 |
|---|---|
| [安装与更新](install-update.md) | 装到哪、怎么更新、怎么卸载、版本怎么追溯 |
| [五步环](five-step-ring.md) | 五个环节各自做什么、产出什么工件 |
| [过程看板](board.md) | 本机网页看板:多项目、批注、欠账、遥测、双主题 |
| [校验](checking.md) | 状态检查器的各模式:什么时候用哪个 |
| [点修与报修](repair.md) | 已交付内容的点修快速通道与报修闭环(两域合为一篇) |
| [遥测](telemetry.md) | 工具记录了什么、在哪、怎么关 |
| [守卫](guards.md) | 危险操作的机器拦截 |

npm 用户安装与上手速览在仓库根的 README;本目录面向想完整了解产品能力的人。
