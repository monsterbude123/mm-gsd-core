# 历史工件三态 —— 旧 PLAN 到底该怎么办

> 面向所有用 mm-gsd 的项目。判据只取**可机器判定的事实**,不看文档新旧 ——
> mtime 只说明改过,不说改的是决策还是格式(改个错别字也会让 mtime 更新)。

## 三态

| 态 | 判据 | 处置 |
|---|---|---|
| **未完成** | 有 PLAN 无 SUMMARY,或 SUMMARY 缺 `status` | **续做不重做**;或明确改成 deferred(写进 CONTEXT 的 deferred,别留半成品) |
| **没记账** | 有 SUMMARY 且 `status: complete`,但 `commits: 0` | **补记账,不重做** —— 原件不动,新件说清关系(见下) |
| **过时** | 功能在仓库里,但本 phase CONTEXT 的决策已改 | 旧 PLAN 在 frontmatter 加一行 `stale_note` 批注(哪条决策变了、被谁接替),**接替票必须真实存在**;**新 PLAN 覆盖它** |

## 为什么「重做一遍」是最贵的处理

重做会把**已验证的成果变成未验证的**,还丢掉中间那些当时才知道的上下文 ——
而那些上下文正是这个决策当初被选中的理由。三态的全部意义就是让人**认出第三种**,
不要顺手把它当成前两种。

## 补记账怎么做(原件不动)

历史工件是审计痕迹,改它就毁了痕迹。补记账的做法是**新件说清关系**:
原件一个字节不动,另写一份记账件声明「本票由 X 覆盖、原 Y 的 commits 实为 Z」。
记账必须指向**真实存在**的 commit —— 指向一个不存在的 sha 的记账等于没记账,
因为「已知悉」三个字就能糊弄过去。

## 豁免台账:存量项目怎么把老工件记掉

记账纪律随包分发后,「声称完成却零 commit」的 SUMMARY 会当场判红 —— **存量项目的老工件会立刻变红**。
豁免台账是随包件,不是可选项:落点 `.planning/artifact-ledger.md`,格式与本仓一致。

| 件 | 缺口 | 记账 commit | 说明 |
|---|---|---|---|
| 05-01-SUMMARY.md | commits | c5c64f9 | 这批改动在 c5c64f9 里 |

**记账 commit 必须在 git 里真实存在** —— 指向一个不存在的 sha,记账不算数:
「已知悉」三个字就能糊弄过去的记账等于没有记账。

**原件不动**:豁免不靠改老 SUMMARY 的 `commits` 字段,靠另记一行说清关系
(「本票的产出在 <sha> 里,本件的 commits 字段是历史笔误」)。
台账是共享记忆,**建议入库** —— 项目若 gitignore 了 `.planning/`,用一条 un-ignore 例外放它进去;
不入库就每人各记一份。

**决策核销不归记账门**:「这张票认领了哪条决策」由 phase 级 union 门判 —— 本 phase 全部票的
`covers` 并集要覆盖 CONTEXT 的全部决策。记账门只判 `commits` 这一种缺口
(「四件套不齐」归 `--plan` 门管)。一个判定只能有一个 owner:两处各判一半,判据还会各说各话 ——
2026-10-22 实测过,按 per-plan 判的那半会把一张合法的纯实现票(`covers: 无`,而 phase 并集已覆盖)判红。

## 「过时」怎么判、怎么免单

机器能判的代理是**反向核对**:票的 `covers` 里认领的决策编号,在本 phase CONTEXT 里已经没有了 ——
即它实现的是已被推翻的决策。这条门会报红,并把该写的那行批注直接给你。

判据只有一条事实:**编号不在 CONTEXT 的决策集合里**。
**别用 mtime 代替这一步**:它只告诉你「改过」,不告诉你「改的是决策还是格式」。

**批注即免单**:确认这张票确实过时(对照本 phase CONTEXT 看哪一条变了),就在它的 frontmatter 加一行批注:

```yaml
stale_note: "D-04 已于 2026-10-22 推翻,本票由 05-02 接替"
```

- 批注**只加 frontmatter 一个字段**,不动正文与决策内容 —— 原件是审计痕迹,改它就毁了痕迹。
- **批注点名的接替票必须真实存在**(有一张对应的 PLAN 文件),否则免单不成立:
  「本票由 X 接替」而 X 不存在,就是钻空子。批注里常带日期(`2026-10-22` 也长得像票号),
  门禁会逐个候选去找,有一个真的存在才算数。
- 批注在,这张票不再被核销门与漂移门判红 —— 它已经被接替,不再按活票处理。
